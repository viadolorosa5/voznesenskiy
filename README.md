# Отель «Вознесенский»

Адаптивный сайт на React, TypeScript и Vite. Фотографии в `public/images` — оптимизированные копии предоставленных ресурсов.

## Запуск

```sh
npm install
npm run dev
```

Проверка production-сборки:

```sh
npm run build
npm run preview
```

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует его на GitHub Pages при push в `main` или `master`, а также вручную. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации. Сборка использует относительные пути, чтобы сайт и изображения работали в репозитории вида `https://<owner>.github.io/<repository>/`.

## Подключение отправки заявок

Без `VITE_BOOKING_ENDPOINT` форма работает как MVP-заглушка: после проверки полей открывается окно успешного завершения, но заявка не отправляется и не сохраняется. Для реальной отправки скопируйте `.env.example` в `.env.local` и задайте `VITE_BOOKING_ENDPOINT` — URL серверного обработчика. Форма отправляет JSON методом `POST`; обработчик должен принимать поля заявки и отвечать успешным HTTP-статусом. Настройте CORS на сервере, если frontend и API размещены на разных доменах.

## Ограничения материалов

Верстка основана на присланном полноразмерном скриншоте страницы и отдельных фотографиях. Исходный Figma-файл и отдельные ресурсы логотипа/карты не были доступны, поэтому маленький знак в шапке и оформление карты реконструированы по скриншоту. Точное совпадение мелкого текста и состояний компонентов с оригинальными фреймами следует сверить после предоставления доступа к ним.
